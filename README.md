# 智能体操作系统中的多智能体协作技术
**2026年全国大学生计算机系统能力大赛 - 操作系统设计赛 (中西部与华南区域赛) - 功能挑战赛道**

## 📖 项目简介
本项目基于 **Linux + AIOS + 端侧大模型 (7B/8B)** 环境，旨在探索并实现操作系统层面的多智能体协作技术。针对单智能体无法完成的复杂任务，本项目基于 AIOS-Agent SDK 设计了一套多智能体协作系统，通过 AIOS 强大的内核调度、上下文管理与资源分配能力，实现了子任务的并行分解与协同执行，显著提升了复杂任务的处理效率。

## ✅ 赛题要求对照说明
本项目严格对照赛题核心要求进行设计与实现：

- **1. 4种以上可协作智能体**：系统包含 `Planner`（统筹规划）、`Coder`（代码编写）、`Reviewer`（代码审查）、`Tester`（自动化测试）四种核心智能体，协同完成软件开发任务。
- **2. ≥4个并行子任务自动分配**：`Planner` 将复杂需求拆解，自动分配给多个 `Coder` 并行开发（如：前端UI构建、后端API开发、数据库设计、测试用例编写）。
- **3. ≥3对双向交互协作**：
  - `Planner ↔ Coder`：任务下发与进度反馈。
  - `Coder ↔ Reviewer`：代码提交与审查意见反馈。
  - `Coder ↔ Tester`：测试执行与 Bug 修复反馈。
- **4. 先后顺序与依赖约束**：利用 AIOS 调度机制，实现基于 DAG（有向无环图）的任务依赖管理，确保“需求分析 -> 并行编码 -> 审查测试 -> 集成部署”的有序进行。

## 🏗️ 系统架构与目录结构

本项目采用 `git subtree` 将 AIOS 开源操作系统内核引入作为底层依赖。

```text
E:\OS
 ├── doc/               # 项目文档（设计说明书、测试报告、参考文档等）
 ├── src/               # 核心竞赛代码

 └── README.md          # 本文件
```

## 🚀 环境准备与快速开始

### 1. 环境要求
- **OS**: Linux (Ubuntu 20.04/22.04 推荐)
- **Python**: 3.10+
- **模型**: 本地部署的端侧大模型 (7B 或 8B，如 Qwen2-7B, Llama-3-8B)

### 2. 配置模型与密钥
为防止敏感信息泄露，本项目通过环境变量读取大模型配置（**请勿将密钥硬编码在代码中**）：

```bash
# 配置本地大模型的 API 地址与密钥
export AIOS_LLM_API_BASE="http://127.0.0.1:8000/v1"
export AIOS_LLM_API_KEY="your_api_key_here"
export AIOS_LLM_MODEL="Qwen2-7B-Instruct"
```

### 3. 运行多智能体系统
```bash
# 进入源码目录
cd src

# 运行系统，通过参数传入需要完成的复杂任务
python main.py --task "开发一个具备用户登录与数据存储的轻量级 Web 博客系统"
```
